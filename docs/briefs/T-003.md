# T-003: Intimate action ladder (O2, part 1)
Role: implementer · Platform: claude (local subagent, worktree) · Milestone: O2

## Goal
When the player types a physical/intimate action ("I take her hand", "I kiss her neck"), the ENGINE decides her response from state, applies stat changes, and the model only narrates that decision. State wins over prose.

## Owner decisions (interview 2026-10-01)
- Engine judges first, then the model narrates the verdict.
- A ladder of ~10 steps (e.g. touch hand → hold hand → hug → cheek kiss → kiss → making out → groping → undressing → oral → sex; tune names to fit existing data). Free text maps to the nearest step.
- Verdicts: accept · hesitate · refuse. Refusal is in-character with a vague hint at what would help (more trust, a private place, sober); small Like/Lust change, never a system error string.
- UI: show stat-delta chips (e.g. +2 Lust, −1 Trust) on the heroine panel. Nothing else extra (no mood line, no next-step hint UI).
- Gates use the existing romance stats (Like/Trust/Lust, hidden Chemistry/Inhibition), sobriety, privacy/witnesses and existing intimacy consent. Lower adult gates per the romance stat model. All characters are adults; nothing past the engine's verdict.

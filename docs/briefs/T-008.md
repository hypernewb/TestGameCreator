# T-008: Unwelcome flirting reacts by personality + per-heroine ladder pace
Role: implementer · Platform: codex · Milestone: O2

## Goal
When a flirt or touch is unwelcome, she reacts in her own way (deflect / tease back / shut down) with matching stat changes, and each heroine climbs the touch ladder at her own pace.

## Read only
- `docs/design/flirt-cap.md`, `docs/design/character-sheet.md` (Owner decisions: unwelcome flirting, rude exit), `docs/briefs/T-003.md` (the ladder), `docs/map/README.md` + `modules.md`, then only the files you need (touch ladder, acts, flirt cap, character-sheet).

## May change
- touch-ladder / acts / flirt-cap modules; `packages/core/character-sheet.mjs` (read helpers); `scripts/reskin-campus.mjs` + `packs/campus.json` (per-heroine data); contracts; `tests/unwelcome-flirt.test.mjs` (new); report.

## Do
1. Reaction style comes from sheet traits by a fixed table (reserved/insecure → deflect; mischievous/rebellious/flirtatious → tease back; guarded/analytical/competitive → shut down when pushed twice), overridable per heroine (`behavior.unwelcomeStyle`).
2. Stat changes (campus defaults): deflect Like −1; tease back Like 0, Lust +1 only if Trust ≥ 30; shut down Like −2 Trust −2. Repeats in one scene escalate one step.
3. The verdict (style + reason) goes to the scene prompt so the model narrates her reaction in voice; no system text.
4. Per-heroine ladder pace: optional `dating.ladderPace` (slow 1.25× / normal 1× / fast 0.8× on existing step thresholds). Trio: yuna slow, haruka normal, minji fast.
5. Never grants consent; body-map limits (T-024) and existing gates still win.

## Rules
- Missing pack field = legacy behaviour. New numbers live in the pack (campus default as given) with a Studio control in its own section. Additive edits only in shared files (studio, app, play, contracts, campus.json, prompt builder); no reformatting.
- No extra model call; anything for the model is injected into the scene prompt, never replaces it; keep prompts lean. Engine judges, model narrates.
- After any campus.json change run `node scripts/reskin-campus.mjs` so `packs/campus-trio.json` stays in sync.

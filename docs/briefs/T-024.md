## Do
1. Acts may carry an optional `region` (one of the 10 sheet regions). Map existing touch-ladder steps to a default region where obvious; unmapped = no region check.
2. Limit check per region: `never` → refuse (hard, runtime consent cannot override); `ask_first` → refuse unless she has explicitly agreed to this region in the current scene (engine-tracked agreement, cleared at scene end); `ok` → falls through to the existing consent/privacy/agreement rules (never grants consent by itself); `null` → exactly today's behaviour.
3. Sensitivity (0–3) scales the applied Lust gain of an accepted act in that region (e.g. ×1, ×1.25, ×1.5, ×2; keep numbers in pack `intimacySettings.sensitivityScale`, campus default as given). Never affects permission.
4. Refusals use the existing refusal path and give a reason code (`limit_never`, `limit_ask_first`) so T-025 can word them. No extra model call.
5. Campus sheets keep all region values null (the owner picks them later); so campus play is unchanged until then.

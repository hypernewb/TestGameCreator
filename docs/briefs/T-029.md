# T-029: Hidden daily need (C1)
Role: implementer · Platform: codex · Milestone: C1

## Goal
Each day each heroine quietly wants something (to vent, have fun, be left alone, be praised, eat, an adventure). Reading her right pays off; the game only hints.

## Read only
- `docs/research/heartmorrow-digest.md` steal 1, `docs/map/modules.md` + `engine.md`, then only what you need.

## May change
- new `packages/modules/daily-need.mjs` + registration; scene prompt injection (one line); mood line hook (vague hint only); packs; contracts; studio section; `tests/daily-need.test.mjs` (new); report.

## Do
1. At day start pick one need per heroine from pack `dailyNeeds` (campus: vent, fun, space, praise, food, adventure), deterministic from seed + day + actor, weighted by her traits.
2. Scene prompt gets a vague behavioural hint ("she seems drained"), never the label; the mood line may show the same hint.
3. When the interpreted turn matches the need (engine judges from act kind/topic tags), once per day: Like +2, Trust +1; acting against it (pushing when she wants space): Like −1. Counts inside the daily cap.
4. Replay and save/load deterministic.

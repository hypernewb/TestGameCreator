# T-030: She texts first (C1, NPC initiative)
Role: implementer · Platform: codex · Milestone: C1

## Goal
Heroines start contact: an evening text, a plan suggestion, a tease, a "you ignored me" when neglected. Texting has its own small gain budget.

## Read only
- `docs/research/heartmorrow-digest.md` steals 3, 4, 7; `docs/map/modules.md` (phone contacts/messages, schedule), `docs/design/stages.md`; then only what you need.

## May change
- phone/messages module or new `packages/modules/outreach.mjs`; phone prompt injection; `public/` phone view (additive); packs; contracts; studio section; `tests/outreach.test.mjs` (new); report.

## Do
1. On each daypart change each heroine may send one text: chance by stage (campus: acquaintance 10%, dating 35%, exclusive 55%, scaled by Like), max 2 a day per heroine, deterministic from seed.
2. Kinds by state: check-in; plan suggestion (a pending invite the player accepts by replying); tease (Lust ≥ 40); neglected (dating+ and no contact for 2 days; Like −1 if still ignored the next day); strain text while T-012 strain is active.
3. The incoming text is a model-free template line per kind from pack data; replying uses the normal one-call reply.
4. Texting replies give at most +2 Like/Trust total per heroine per day, inside the daily +6 cap.

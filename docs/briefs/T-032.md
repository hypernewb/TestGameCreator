# T-032: Anniversaries and shared history (C1)
Role: implementer · Platform: codex · Milestone: C1

## Goal
The relationship remembers itself: every 28 in-game days after you start dating she marks it, and she brings up key shared moments when they fit.

## Read only
- `docs/research/heartmorrow-digest.md` steal 5, `docs/design/stages.md`, `docs/map/modules.md` + `ai.md`, then only what you need.

## May change
- dating/history module or new `packages/modules/anniversary.mjs`; prompt injection (one short block); packs; contracts; `tests/anniversary.test.mjs` (new); report.

## Do
1. Record key moments per heroine (first meeting, first date, intimate firsts, stage changes, breakup/reunion) with day and place; keep max 8 (drop the oldest non-first).
2. Every 28 in-game days from dating start: the scene prompt gets "today is your N-month mark" plus up to 2 shared moments; acknowledging it gives Like +2 once; no contact that day gives Like −1.
3. On normal days include 1 shared moment only when place or topic matches (one line at most).
4. Survives save/load and breakups.

## Rules
- Missing pack field = legacy behaviour. New numbers live in the pack (campus default as given) with a Studio control in its own section. Additive edits only in shared files (studio, app, play, contracts, campus.json, prompt builder); no reformatting.

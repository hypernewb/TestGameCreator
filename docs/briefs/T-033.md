# T-033: Gift repeats lose value + keepsakes
Role: implementer · Platform: codex · Milestone: C1

## Goal
Giving the same thing again counts for less; meaningful gifts become keepsakes she can mention.

## Read only
- `docs/research/heartmorrow-digest.md` steal 2, `docs/design/character-sheet.md` (gift categories), `docs/map/modules.md` (gifts), then only what you need.

## May change
- gifts module; character-sheet gift category reads; packs; contracts; studio section; `tests/gift-repeats.test.mjs` (new); report.

## Do
1. Same item to the same heroine: 1st full value, 2nd ×0.5, 3rd and later ×0 (pack `giftRepeatScale:[1,0.5,0]`), per heroine for the whole save.
2. Wire sheet gift categories: liked category +50% (rounded), disliked category Like −2. Item-specific rules still win.
3. Gifts with a net Like gain ≥ 3 become keepsakes (max 5); the scene prompt may mention one when relevant (one line at most).
4. The repeat penalty is an in-story cue ("she smiles politely"), not a number.

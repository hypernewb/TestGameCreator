# T-040: Her own wants (C1)
Role: implementer · Platform: opencode-openrouter · Milestone: C1

## Goal
Each heroine wants something right now (a quiet night in, help with an exam, to try the new bar) and brings it up. Helping with it pleases her more this week, so she feels like a person with her own life.

## Read only
- `docs/design/character-sheet.md`, `docs/map/modules.md` (dating, gifts, schedules), `docs/research/heartmorrow-digest.md`; then only what you need.

## May change
- new `packages/modules/wants.mjs` or the dating module; character-sheet reads; prompt injection (one line); packs + reskin script; contracts; studio section; `tests/wants.test.mjs` (new); report.

## Do
1. Sheet `wants`: a list of {id, text, keys, reward}. Each heroine has 1-2 active wants, rotated weekly (deterministic from the save seed).
2. The scene prompt gets one line "she has been wanting <text>" when she is present (max one heroine line per turn).
3. A player act or plan matching the want keys fulfils it: Like +reward (campus default 3, counts against the daily cap), the want is retired, a new one rolls next week.
4. Trio: 4 wants each in the reskin script, drawn from her existing bio (no contradictions with campus.json).
5. Test: rotation deterministic, prompt line present only when she is present, fulfilment pays once.

## Rules
- Missing pack field = legacy behaviour. New numbers live in the pack (campus default as given) with a Studio control in its own section. Additive edits only in shared files (studio, app, play, contracts, campus.json, prompt builder); no reformatting.
- No extra model call; anything for the model is injected into the scene prompt, never replaces it; keep prompts lean. Engine judges, model narrates.
- After any campus.json change run `node scripts/reskin-campus.mjs` so `packs/campus-trio.json` stays in sync.

## Acceptance (all)
- New test file passes; `npm test` no new failures (4 known worktree art failures OK; list them). Existing assertions not weakened.
- Report lists every changed file and any deviation. Do NOT commit.

## How each item works

1. **Calendar** — `calendarLine(context)` renders `Day N, Weekday.` once in the user message, from `contextFor`'s engine clock (`calendarFor`). No clock in context (legacy pack) → no line. The existing `assertWeekday` lint is unchanged and still catches a wrong day.
2. **NPC locations** — `context.absentCharacters` gained `where` (the actor's real location from world state), and `awayLine` groups the away NPCs by place, so two people in one hall cost one group. Capped at `AWAY_GROUPS = 2` places to hold the token budget; `Absent NPCs stay put.` is the rule that covers anyone the line leaves out, on top of the existing closed-attendance sentence. Nothing is invented for an actor with no known location.
3. **RESULTS dedup** — `contextFor` now builds `outcomes` through a loop that keeps the first outcome per distinct `payload.text`. Distinct lines, their order, their types and the existing visibility filter are unchanged; `MockProvider.narrate` consequently plays a repeated result once.
4. **Echo and prop** — two short style lines in the system prompt (scene prompts with a cast). The post-check is warn-only in the lint pass: `echoedRun` finds any run of `pack.slipGuard.echoWords` consecutive player words inside the reply and `lintScene` pushes `{check:'echo',warned:true}` into the existing `warnings` list, which the provider records in `turn.lintTrace`. It never throws, never asks for a repair and never blocks the reply. No pack field = legacy behaviour (no check).
5. **Token budget** — the five items above, measured as the rendered prompt minus the same prompt with those five lines removed.

Pack and Studio: `packs/campus.json` carries `"slipGuard": {"echoWords": 8}` (the number as given in the brief), propagated to `packs/campus-trio.json` by `node scripts/reskin-campus.mjs`. `public/studio.mjs` gets its own section, "Narrator slips", with one number field; a pack without `slipGuard` shows "This pack has no narrator slip guard." `packages/contracts/index.d.ts` gains `SlipGuardPack` beside the other pack interfaces.

Still inside `packages/ai/`, still additive, no new model call.

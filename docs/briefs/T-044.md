# T-044: First-run setup: bring your own key
Role: implementer · Platform: codex · Milestone: F1

## Goal
A friend opens the game for the first time and is walked through connecting a free cloud model (Gemini free tier or OpenRouter free) in under 2 minutes, without reading docs.

## Read only
- `docs/NEXT-MILESTONES.md` (F1), the AI settings code in `server.mjs` and `public/app.mjs`, `packages/ai/providers.mjs`; then only what you need.

## May change
- `server.mjs` settings routes (additive), `public/app.mjs` + css, `packages/ai/providers.mjs` (presets only), `tests/first-run.test.mjs` (new); report.

## Do
1. When no usable AI connection is configured, the app opens a 3-step setup instead of the game: pick a provider preset (Gemini free, OpenRouter free, local LM Studio, custom), paste a key (with a link to where to get one), test it.
2. "Test connection" makes one tiny request and shows a plain result: works / bad key / no internet / rate limited, never a raw error dump.
3. The key is stored where settings are stored today; it is never logged, never sent back to the client after saving (show only the last 4 characters), never put in a URL.
4. Settings stay changeable later from the existing settings screen; already-configured users never see the setup.
5. Test with a mock provider and a temp `dataPath`: fresh install shows setup, good key passes, bad key gives the plain message, the key never appears in any response body or log line.

## Rules
- Missing pack field = legacy behaviour. Additive edits only in shared files (server, app, play, providers, contracts); no reformatting.
- No extra model call per normal turn. Engine judges, model narrates.
- NEVER open or write `data/ai-settings.json`. Tests and experiments use `createApp({dataPath})` with a temp dir or `:memory:`.
- Never put real API keys in code, tests, fixtures or logs; use obvious fakes like `test-key-123`.

## Acceptance (all)
- New test file passes; `npm test` no new failures (4 known worktree art failures OK; list them). Existing assertions not weakened.
- Report lists every changed file and any deviation. Do NOT commit.

# T-045: Free-tier guard
Role: implementer · Platform: codex · Milestone: F1 / fun gate (input never lost, cost recorded)

## Goal
Playing on a free cloud tier never loses a turn: when the model says "too many requests" or times out, the game waits, retries, and tells the player in plain words. Calls and tokens per hour are recorded.

## Read only
- `packages/ai/providers.mjs`, the turn path in `packages/ai/service.mjs`, `docs/NEXT-MILESTONES.md` § Fun gate (input never lost, cost recorded); then only what you need.

## May change
- `packages/ai/providers.mjs`, `packages/ai/service.mjs` (turn path, additive), `public/play.mjs` status line, contracts, `tests/free-tier-guard.test.mjs` (new); report.

## Do
1. On HTTP 429 / 503 / timeout: honour `Retry-After` when present, else back off 2s/5s/12s (max 3 retries, total wait capped at 30s). The player sees "The model is busy, retrying in 5s...".
2. If retries run out, the typed input stays in the box (not discarded), no state is committed, and the player sees a plain message with a Retry button. Replay never calls the model, as today.
3. Record per campaign: model calls, prompt/completion tokens (from the provider response when given), retries, per real-time hour. Expose it to `npm run fun -- --campaign latest`.
4. Test with a mock provider that returns 429 twice then succeeds (turn lands once), and one that always returns 429 (input preserved, nothing committed, counters correct).

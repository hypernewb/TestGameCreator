# T-071: Bare-pack smoke test (modules run without campus data)
Role: implementer · Platform: opencode (longcat-2.5-preview-free) · Milestone: Creator portability

## Goal
Prove every module survives a world that has none of campus's content. This is a test-only safety net for the game creator.

## Read only
- docs/roles/implementer.md, packages/modules/index.mjs and each module's init/validate/execute/react shape, packs/neutral.json, packs/template-fantasy-town.json, existing tests that build apps (e.g. tests/framework.test.mjs top helpers) for how to create an app/state from a pack object.

## May change
- tests/bare-pack-smoke.test.mjs (new). If a module crashes on a bare pack, do NOT fix it: record it with `test.todo`/skip + a line in the report.

## Do
1. For each of packs/neutral.json, packs/template-fantasy-town.json, packs/template-bar.json: create an app via the normal path with `:memory:` DB (never touch data/).
2. Run pack validation, init, then 3 neutral turns (look, wait, one movement) using the mock provider; assert no throw, state serialises, save digest builds, and every module's `datingContext`/`context` hook returns without error.
3. Also run with a pack where each optional module option is explicitly absent (delete `pack.dating`, `pack.recap`, `pack.endings`, `pack.director`, `pack.phone`... one at a time) and assert still OK.
4. Report which modules crash on which pack, as a table, in docs/briefs/T-071.report.md.

## Acceptance
- `node --test tests/bare-pack-smoke.test.mjs` passes (known crashes are listed skips, each named in the report).
- Full `node --test tests/*.test.mjs` unchanged otherwise.

## Out of scope
- Fixing modules, touching packs, scenePrompt.mjs, beats.mjs.

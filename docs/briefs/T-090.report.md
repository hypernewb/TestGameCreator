Never use the repo template unchanged with denoise=1.
3. Suggested starting grid (experimental, not validated): batch 1, fixed new seed, DPM++ 2M/Karras, 24 steps, CFG 5, denoise 0.15/0.25/0.35, same source resolution. Lower denoise preserves more reference structure but may barely change expression; higher values increase model/style/identity drift. No seed or adapter guarantees identity.

Verify mask polarity. Reuse original alpha and silhouette if unchanged, then check edges over cream, charcoal and terracotta. This confines changes more strongly than full-frame img2img; altered body poses need fresh alpha and separate approval/testing.
5. Save experiment masters/workflow/seed/parameters outside runtime assets, then fit/pad one accepted variant to the art contract. No automatic sync, runtime assignment or cutout-script overwrite. Owner reviews source/result side by side at face crop and runtime scale before adoption.
6. OpenPose is optional only for a later approved pose task, after checkpoint compatibility check. It offers skeletal alignment while identity remains vulnerable; it is unnecessary for the first same-pose expression edit.

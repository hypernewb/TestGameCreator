# T-107: Character Chat Lab (one character, stranger → final stage, no game)
Role: implementer · Platform: codex (planned) · Milestone: CQ-A (conversation quality, revision 2026-10-06b)

## Goal
The owner can chat with one character from first meeting to the last route stage without playing the game. They can see exactly how the route reacts and judge the conversation. Workers can run the same thing headless as a scripted arc that produces transcripts and metrics. The Lab becomes the measuring stick for every conversation change (T-108 to T-114).

## Do
1. **Isolated session.** A Lab session is an isolated temp or `:memory:` campaign, seeded from the selected project, with only the chosen NPC in the scene. It never writes the project's real campaigns. It never reads data/ai-settings.json: the provider comes from the server's existing settings API, not from file reads in the Lab.
2. **Real pipeline.** The chat pane uses the real turn pipeline (same prompt, same pricing, same firsts and stages), so what the Lab shows is what play does.
3. **Live side panel.** It updates every turn and shows:
   - all relationship stats, including hidden ones (the Lab is a debug view);
   - the current stage and the next unlock conditions, each marked met or unmet;
   - the firsts that are available;
   - goal/quest progress, once T-110 exists (feature-detect);
   - the last delivery verdict, once T-109 exists (feature-detect);
   - the acts priced this turn, with reasons.
4. **Controls:**
   - skip time by an hour, day or week (through the normal time commands);
   - jump to a stage (applies the stage's minimum state as a lab-only patch, labelled as such);
   - player stat sliders;
   - reset;
   - provider pick (mock, local or cloud);
   - fork from turn N.
5. **End summary.** Shows the stage reached, the turn count, stat changes, firsts, and which lines moved what. The transcript can be exported as markdown.
6. **Build stamp.** Show the server start time, the git short hash and the prompt hash. If any file under `packages/` or `vendor/` changed after the server started, show the banner "server older than files on disk". This closes the stale-4317 trap.
7. **Latency.** Record time-to-first-token, total time and prompt tokens for each turn. Show them in the side panel and in the headless metrics.
8. **Headless runner.** Generalise `sustained-conversations` beyond jana:
   - Player lines come from a script file: plain lines plus lab commands (`/skip day`, `/stage <id>`, `/stat charm 9`).
   - It runs against any pack and NPC.
   - It reuses `dialogue-metrics` (question-ending rate, repeated phrases, line length, speaker share) and adds the stage reached, the turns at which unlocks happened, and the verdicts seen.
9. **Two builtin scripts**, to show route differences:
   - `stranger-to-close`: 20 turns of greeting, talking interests, helping, flirting, asking out and a kiss;
   - `slow-player`: talk only, no flirting.

# T-111: Route Map editor + route archetypes (absorbs P4)
Role: implementer · Platform: codex (planned) · Milestone: CQ-A (creator)

## Goal
A visual route editor for each character, like the ones in VN creators: a graph of stages, the gates between them, firsts, goal steps and authored events.

Route archetypes make routes feel different from character to character: slow burn for some, fast burn for others. A sameness check warns when the cast's routes look alike.

This absorbs assessment proposal P4 (the visual stage-unlock / promise-condition spec).

## Do
1. **The graph.**
   - Columns are stages, in order. Nodes are stages, firsts, goal steps and events. Edges are requirements, using the conditions schema.
   - Clicking a gate opens a condition picker: stat ≥, trust ≥, flag, goal step, first done, days since, promise kept.
   - Edits write the existing progression/conditions JSON. No new runtime schema, except what P4 specified.
2. **Archetype presets.** Apply one per NPC; everything stays freely editable afterwards.
   - **Fast burn:** early chemistry gates and low inhibition; commitment comes late.
   - **Slow burn:** trust gates first, a long tempo, big-payoff firsts and a higher reward per step.
   - **Goal-first:** stages require her goal steps.
   - **Trust-first:** no physical first until the trust stage.
   - **Push-pull:** a stage can slip back when she's neglected, and can be repaired.
   - **Rival/jealous:** reacts to other routes.
3. **Sameness check.** Compare the cast's routes (gate types, tempo, stage count) and warn, e.g. "3 of 4 characters share the same route shape".
4. **Validation.** Flag unreachable stages, gates that reference a missing stat or flag, and cycles. Show the problems on the graph.
5. **Simulate link.** A read-only link opens the Chat Lab (T-107) at a chosen stage, when the Lab exists.

# T-113: Generated depth: characters and worlds that have something to say
Role: implementer · Platform: codex (planned) · Milestone: CQ-C (after the T-108, T-110 and T-111 schemas)

## Goal
Generated characters and worlds are as deep as the hand-built campus.
- **Every NPC has:** a goal, a speech profile, tells, topics, backstory hooks, secrets, wants and a route archetype.
- **Worlds have:** like clues, outreach, gossip, scene feedback and pacing.

Existing projects get an "Enrich" action.

## Do
1. **Depth-parity check.** List the fields that the campus pack fills and that drive play: goal, speech, tells, topics, like/dislike clues, wants, secrets, arc stages, route archetype, outreach lines, gossip, sceneFeedback and pacing. Test that a generated mock world fills all of them.
2. **Variety across the cast.** Generation gives each character distinct speech tics, uses at least two different route archetypes, and writes goals that involve different places and people.
3. **Enrich.** For an existing project, generate only the missing fields, as proposals. Never overwrite authored values.
4. **Blanks stay blank.** Fields the creator leaves blank stay blank for the game to improvise (an existing decision). Enrich is opt-in.

## Acceptance
- Mock generation passes depth parity on both campus-like and non-campus prompts (T-076).
- Enrich on a fixture project fills only the missing fields, and the review UI accepts or rejects each field.
- One owner-approved cloud generation sample is attached to the report.
- `npm test` is green.

# T-114 report: context hygiene and local speed

Worker: Claude (director session), worktree `sf-wt/T-114`, not committed.

## Changes
- **New `packages/ai/prompt-sections.mjs`.** This is the section helper.
  - `proseOf` flattens a state record into "key value; key (nested)" prose. Empty and false fields drop out, and nesting stops at depth 2.
  - `intimacyProse`, `npcProse` and `firstProse` are thin wrappers over it.
  - `awayFrom` blanks an absent character's place when it is the scene's own room.
  - `timeLine` is the volatile when/where header.
  - `stablePrefix` returns system + user text up to that header, which is the cacheable head.
- **Memory (`memory.mjs`, Do 1).**
  - `classifyUtterance` gains two kinds:
    - `action`: an imperative physical verb ("Touch her hand…"), or "I <verb> <object/preposition>" ("I lean closer to her"). Plain "I watch anime" stays a disclosure.
    - `meta`: "Go talk to X", "Find X". These are never remembered.
  - "Tell me / <player name> more about…" now counts as a question, so it is dropped. Callers pass `{player}`.
  - Actions are phrased in the past tense as something the player did: "With Selma Aydın, Ari Kesler touched her hand while flirting with her".
  - Actions share the `statements` slot (last 4) with plain statements.
  - This runs at read time only, so stored memories need no migration.
- **No JSON (Do 2).** These spots were `JSON.stringify` and are now prose:
  - scenePrompt's intimacy bits, BETWEEN OTHERS (`npcProse`) and PRIVATE FIRST MOMENT (`firstProse`);
  - context-budget's flag-object patch and event-payload fallback.
  - The only JSON left before the output contract is the system message's Speaker-ID output example, which is contract, not state.
- **Location (Do 3, `context.mjs`).** For the player or a cast member of the open scene, the context location now comes from `s.scene.location`, not from a stale `actors[id].location`. Characters outside the scene are unchanged. The AWAY line no longer places anyone "away" in the scene's own room.
- **Ordering (Do 4).**
  - Before, the user message ran PREMISE → SETTING → CURRENT STATE → when/where → YOU → profiles.
  - Now the cast profiles come before the when/where line.
  - So system + premise + setting + profiles form a byte-identical prefix across a scene's turns. The time, location, stats, memory, history and this turn all follow it.

## LM Studio advice (report only; ai-settings untouched)
- `n_gpu_layers=999999` skips LM Studio's fit check. A 27B model at a large context then spills KV/weights into shared RAM, which makes every token slow.
- Either let auto-fit choose the layers, or lower the offload until VRAM shows headroom.
- Use about an 8k context for local tests and a Q4_K_M quant.
- With the new stable prefix, keep the same model loaded between turns so prompt caching can reuse the head.
- Judge fun on the cloud model. Local is for correctness and regression checks.

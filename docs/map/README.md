# Codebase Map

- [AI](ai.md): AI-related modules for prompt building, context budgeting, memory retrieval, and model providers.
- [Contracts](contracts.md): Shared TypeScript type definitions.
- [Docs](docs.md): Documentation files.
- [Engine](engine.md): Core game engine logic including world creation, execution, and state mutations.
- [Modules](modules.md): Gameplay modules like social, dating, romance-network, etc.
- [Packs](packs.md): Content packs for the game.
- [Persistence](persistence.md): Data storage and migration utilities.
- [Public](public.md): Browser-based UI components.
- [Server](server.md): HTTP API and server-side integrations.
- [Tests](tests.md): Test files for the framework.

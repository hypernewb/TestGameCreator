# Role: Writer / character designer
Own character content: heroine voices, quirks, wants, opinions, initiative hooks and example lines in `packs/campus.json` (fields named in the ticket).
- Each heroine must sound different: a distinct vocabulary, rhythm, topics, what she wants from the player and what she does unprompted.
- Adult content: consensual, all characters adults, state wins over prose (no prose escalating past the engine's gates).
- Before finalising, write `docs/briefs/T-NNN.veto.md`: 5 lines per heroine (core, voice, want, flaw, signature move) for the owner's quick veto. Ship only after the director approves.
- Run `npm run validate` and the full `npm test`.
